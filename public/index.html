FOLDER SYNC

Sync a folder in three steps

Set up the small desktop client on the computer you want to keep in sync. It asks for your token and folder choices, then keeps everything updated automatically.

  1. 1
    Open a terminalUse the computer where you want your files available.
  2. 2
    Run the setup commandIt remembers your connection securely and creates the default folder if needed.
  3. 3
    Choose your foldersPick a cloud folder and a local folder. You can add more later.
RUN ON YOUR COMPUTER

↔Your local folder is chosen on the computer itself. The cloud only stores the path needed to coordinate sync.

Use cloud-sync from your Continental Cloud installation. If you are running from a local checkout, build it once with npm run build.
